# 澄学 EJU 3.0 前端接口缺口

前端读 `/api/state` 与题库，复用 `shared/` 的页面选择器。所有持久写入经 `/api/action` 并带档案修订号。以下缺口以当前分支的服务实现为准。

| 范围 | 需要的能力 | 当前前端处理 |
| --- | --- | --- |
| 学习档案恢复 | 通过本机 API 校验完整 v3 档案，备份现档后原子替换，并明确设置修订号与活动会话的处理。 | 设置可导出档案、选取文件并检查 v3 的结构，保存名为 `state-v3.json` 的恢复副本。替换要在本机服务退出后手动完成。 |
| 助教上下文 | 支持按页面、考点和笔记提问，支持结构化多轮消息；连接检查能区别 CLI 存在与实际登录。 | 当前题直接带题号和作答。考点或笔记用同考点的题目带入，追问附上最近对话；无有效题号时提供本周复盘。状态检查报告能否找到 CLI。 |
| 跟学播放器 | 可暂停或重新排列活动块，且能记录手动整理块自己的累计用时。支持继续保留同一块在后端的当前题位置及跳转。 | 暂停控制前台计时。上一节回看已完成的题段，下一节先确认结束当前题段；完成后按引擎选的下一项前进。题目位置、未发送草稿、休息和手动任务计时用当前窗口的会话存储恢复。 |
| 背诵卡 | 直接提交三档自评，返回卡片复现时间与同组稍后重现信息。 | 三档映射为放弃、答对但没把握和有把握答对，由现有间隔复习更新到期日。 |
| 本机外观和导航 | 档案设置可存场景、粒子和视差；macOS 导航菜单发送七区命令并更新菜单快捷键。 | 外观三项存浏览器或 WebView 本机偏好。网页处理 ⌘1–7，原生桥接收旧菜单命令并映射至对应新版页面。当前原生壳仍拦截 ⌘1–4，其中 ⌘2–4 会沿用旧菜单的页面映射。原生缩放仍由 WebView 处理。 |
| 查阅历史 | 下架题的完整内容快照或兼容标识。 | 旧会话和分数仍可见，缺失的题显示识别信息，无法打开原题。 |

场景资源当前为冬、春、初夏各昼夜两张。自动模式沿用设计系统的季节与昼夜切换。页面复用实际存在的三首钢琴音轨。
