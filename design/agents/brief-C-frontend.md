# 委托书 C：澄学 EJU 3.0 前端接线（`app/`）

你在 `~/Projects/eju-study`（分支 `v3-glass`）工作。直接开始干，不用先问我。

## 你要做的

把新前端 `app/` 从“设计原型”变成真正能用的 App：所有页面接上引擎的数据和动作，所有界面文字用 Carbon 写的文案，视觉严格按设计系统和原型来。

先读（按顺序）：
1. `design/ux-spec.md` —— 信息架构、每页构图、交互、快捷键（这是需求）。
2. `design/api-contract.md` —— 引擎的状态、接口、actions、selectors（GPT 引擎代理写的，`shared/` + `server/`）。
3. `app/src/ui/ui.tsx`、`app/src/ui/ui.css`、`app/src/ui/icons.tsx`、`app/src/shell/*`、`app/src/styles/*` —— 设计系统（设计师写的）。
4. `app/src/proto/*` —— 每个页面的高保真原型（模拟数据）。**真实页面的构图、层级、组件用法、间距要和原型一致**；原型里的文字只是占位。
5. `app/src/copy/zh.ts` —— 全部界面文案（Carbon 写的，586 条，键上方有注释说明用在哪里）。

旧版 `web/` 只用来参考怎么调接口、怎么渲染 KaTeX / 图片（`web/src/components/RichText.tsx`、`web/src/components/question/*`、`web/src/lib/*`），可以移植逻辑，**不要沿用它的布局和样式**。

## 页面与功能（按 ux-spec 第 1、5 节）

- 外壳：`Shell` + `NavPanel` + `Dock` + `Scene`。导航七项 + 设置；倒计时；复习到期计数；胶囊在学习进行中显示上一个/暂停/下一个、当前任务、计时、进度，空闲时显示开始今天；胶囊右侧：助教、笔记速查、背景音乐。
- **今天**（含跟学）：光球（120 刻度 = 今天 120 分钟，学过的点亮）、今日安排台本、助教一句话、预测分与本周；侧面板今日队列；休息日与漏学后的状态；“开始今天的 2 小时”进入引导式学习，按计划顺序走完、带休息提示。
- **计划**：路线图（阶段、里程碑、今天）、周视图（可切到月）、学习日选择、挪日/跳过/补学。
- **练习**：科目分段、按考点（掌握度砖 + 侧面板考点详情）/ 按真题卷 / 校内考 / 搜索（⌘K 全局搜索题目与笔记）。
- **复习**：到期错题 + 易错点 + 背诵卡一个队列；背诵卡翻卡（空格翻面，1/2/3 自评）。
- **模考**：EJU 整卷（数学 80 分钟、理科 80 分钟）、校内考套卷、成绩回看。
- **笔记**：目录 + 阅读区（弱项置顶）。
- **数据**：预测分区间、每周复盘、弱项热力、每日时长、速度。
- **做题器**（专注模式 `#/session/:id`）：选择题、数学答题卡（blanks）、记述题（看标准解答→逐条勾评分细则；或输入答案让 AI 批改）；解析三段式 + 考点/易错；没把握标记；问助教；答题卡总览；快捷键（ux-spec 第 8 节）。
- **AI 助教**：胶囊呼出的 `Sheet`（参考 `CoachProto`），自动带上下文（当前题/页面），追问、变式题（显示“正在出题并另算一遍核对”）、批改、每周复盘；异步任务轮询按接口文档来。
- **首次引导**：三步（目标院校与各科目标 → 学习日与时长 → 起点成绩，已预填）。
- **设置**：外观（场景自动/固定 + 6 张缩略图、天气粒子、视差、明暗跟随场景）、背景音乐、目标、学习日、AI 助教模型、数据导出/导入。
- 原生桥：移植 `web/src/lib/native.ts`（菜单命令、缩放、⌘1–7 等）。

## 规则

- **样式**：页面只组合 `ui/` 与 `shell/` 的组件；需要页面级 CSS 时放在 `app/src/pages/<区>/<区>.css`，**只能用 tokens.css 里的变量**，不写死颜色/圆角/阴影/模糊。原型里已有的页面级样式（`app/src/proto/proto.css`）挪到对应页面的 CSS 里用。缺组件就照现有组件的风格补在 `ui/` 里，并在最后的回复里列出来。
- **文字**：用户能看到的每个字都来自 `app/src/copy/zh.ts`。**不要改 `zh.ts`**；缺的键写进 `app/src/copy/zh.pending.ts`（同样的结构，先放一句简短占位，每条上面注释用在哪里），页面从合并后的对象取（`copy/index.ts` 导出 `t = merge(zh, pending)`）。之后 Carbon 会把 pending 里的改写并并入 `zh.ts`。
- 题干、解析、笔记这类内容按原样渲染（KaTeX、图片），题干用日语字体，阅读区用 `glass-read`。
- 不要改 `shared/`、`server/`（引擎）、`content/`（题库）、`desktop/`。如果接口不够用，写进 `design/frontend-needs.md`，用最小的前端侧变通先跑通。
- `app/src/main.tsx` 改成真正的入口；原型保留在 `#/proto/*`（开发参考），正式路由按 ux-spec。
- `package.json`：加 `dev:app`、`build:app`，`build` 改成 题库 + `app`。旧 `web/` 在一切跑通后移到 `legacy/web-v2/`（并修好 tsconfig / 脚本里的引用）。
- 检查：`npm run typecheck`、`npm run build` 必须通过；写一个 node 冒烟测试（用 `react-dom/server` 拿测试状态把每个页面渲染一遍，确保不崩），放在 `tests-v3/`。不要下载浏览器。
- 提交：分几次有意义的提交，只提交你改的路径。
- 最后一条回复写：完成了哪些页面和功能、新增的组件、`zh.pending.ts` 里有多少条、`design/frontend-needs.md` 里有什么、还没做完的部分。

## 补充

- 本机学习档案是 `data/state-v3.json`（引擎刚从 v2 迁移生成，是真实数据）。你跑服务做测试时一律用副本：`EJU_DATA_DIR=<临时目录> PORT=18765 node server.mjs`，不要动 `data/` 下的文件。
- 题库委托 B 还在往 `content/` 里加题（弱项题、背诵卡、校内考记述题），你不用等它；页面按接口取数据，题多了自然出现。
