## 要做的事

1. **状态模型 v3 + 迁移**：从 `data/state-v2.json` 迁移（保留数理化作答/进度；日语、词汇移入 `legacy` 存档不再参与计算）。只在副本上测迁移，**绝不改动真实的 `data/state-v2.json`**；新状态写到新文件（例如 `data/state-v3.json`），原文件不动。首次启动的引导默认值按上面的画像。
2. **计划器 v3**：长周期分阶段（你按学习科学定阶段与时间点，例如 基础补弱 → 专项强化 → 综合+校内考 → 冲刺），周节奏（新学 / 交错练习 / 间隔复习 / 每周限时小测 / 每月整卷模考），每个学习日 ≈120 分钟由若干任务组成；按“薄弱度 × 考试权重”分配；错题间隔复习；每天根据真实作答自适应（每个考点的掌握度与速度）；处理漏学、挪日、休息周；同一天输入同一状态时结果确定、可解释（每个任务带结构化的 `why`）。
3. **智能层（用户原话：“APP 要很智能”）**：
   - 每个考点的掌握度模型（带遗忘，例如 Elo/BKT + 衰减），按掌握度自动调节难度梯度；
   - 诚实的分数预测（区间，样本少时说明数据少）；
   - “下一步做什么”的推荐（打开 App 就知道该干嘛）；
   - 猜题/慢题检测（答对但耗时远超目标、标记“猜的”等）；
   - 每周复盘数据（本周完成度、进步最多/最该补的考点、下周调整建议的结构化数据）；
   - AI 助教（扩展 `server/coach.ts`，用本机已登录的 codex CLI，保持只读沙箱 + schema 输出的安全做法）：(a) 针对某题追问（已有）；(b) 按评分细则批改记述题（校内考）答案；(c) 为错题生成一道同类变式题，并由第二次独立求解核对答案一致才给学生；(d) 每周计划复盘的自然语言建议。模型可配置，默认 `gpt-6.2-astra`、effort `medium`（交互要快）。
4. **记述题格式 `written`**（校内考用；B 会按下面的形状写题，你实现类型、作答流程、自评/AI 批改与统计）。形状固定如下，双方都按这个来：

   ```jsonc
   {
     "id": "school-meiji-phys-01",
     "subject": "physics",               // math | physics | chemistry
     "topic": "phys.em.induction",       // taxonomy 考点
     "difficulty": 3,
     "targetSec": 1200,
     "source": { "kind": "school", "school": "meiji", "label": "明治大学 理工学部 留学生入试风格 · 原创" },
     // school 取值：waseda | meiji | aoyama | rikkyo | chuo | hosei
     "stem": "（日语题干，可含 KaTeX 与 figures）",
     "format": "written",
     "written": {
       "parts": [
         {
           "id": "1", "label": "(1)", "prompt": "（小问题干，可空）", "points": 10,
           "modelAnswer": "（日语或中文的完整标准解答，含关键式子）",
           "rubric": [ { "text": "列出法拉第定律 V = BLv", "points": 4 }, { "text": "…", "points": 6 } ],
           "final": "（最终答案的简短形式，便于对答案，可空）"
         }
       ]
     },
     "explanation": { "zh": "…", "keyPoints": ["…"], "traps": ["…"] }
   }
   ```
   学生在纸上写，然后看标准解答逐条勾评分细则得分；或者输入最终答案/拍照文字让 AI 按细则批改（先做文字输入）。

5. **去重与精简**：v2 有不少重叠（今日 / 跟学模式 / 冲刺计划；错题本 / 易错点 / 考点速测；数据页重复统计）。v3 的领域模型要支撑新前端的七个区：
   - **今天**：一次引导式 2 小时学习（把跟学模式并进来，按学习科学排顺序，含休息）
   - **计划**：到 6/20 的路线图 + 周视图 + 学习日设置
   - **练习**：按考点 / 按真题卷 / 搜索 / 校内考
   - **复习**：错题 + 易错点 + 间隔复习 + 无机背诵卡合成一个队列
   - **模考**：EJU 整卷模考 + 校内考套卷
   - **笔记**：考点笔记
   - **数据**：掌握度、预测、时长、每周复盘
   删掉真正多余的东西；有取舍时写进文档说明理由。
6. **接口文档 `design/api-contract.md`**：新前端需要的一切——每个 HTTP 接口、状态结构、actions、selectors/派生数据、AI 助教的异步任务接口，带示例。保持服务只监听本机、现有的安全检查。`shared/actions.ts` 这套 store/action 架构如果合理就沿用。
7. **测试**：更新或新建单元测试（`tests-v3/` 或改 `tests-v2/`）：整段计划（2026-11-19 → 2027-06-20）每个学习日约 120 分钟、每周 5 天、没有日语、薄弱考点时间明显更多、模考间隔合理、最后一周减量、挪日/漏学后重排正确；迁移测试（在 `data/state-v2.json` 的副本上）。`npm run typecheck` 与 `npm test` 必须通过（typecheck 若因旧 `web/` 报错，把 `web/` 从 tsconfig 排除即可，不要去改 `web/`）。旧的 e2e 不用跑。
8. **服务**：`server/main.ts` 支持 `EJU_WEB_DIST` 指向新前端（之后会是 `app/dist`），默认值改成 `app/dist`（目录不存在时回落到 `web/dist`）。版本号改为 3.0.0。
