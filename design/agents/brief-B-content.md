你在 `~/Projects/eju-study`（git 分支 `v3-glass`）工作。直接开始干，不用先问我。先读 `content/AUTHORING.md`、`content/taxonomy.json`、`shared/types.ts`，再看几份现有题目文件学格式。

## 学生

- 上次 EJU（2026-11）：数学コース2 约 132/200；理科（物理+化学）约 120/200，化学稍好。**日语非常好**：题干一律用日语原样即可，`stemZh` 中文翻译不再需要（新写的题可以不写 `stemZh`）；解析用中文（`explanation.zh`）。
- 目标：早稻田（理工三学部）/ MARCH 理工系，**目标不设上限**。
- 薄弱（这次的重点）：
  - 物理：電磁誘導、コンデンサー、ばね（弹簧·单振动）、単振り子
  - 化学：無機化学中要背诵的部分、有機化学流程题（构造决定·合成路线）、熱化学計算题
  - 数学：数列、場合の数（排列组合）、指数·对数、積分（特别是置換積分）
- 擅长：物理 電気回路、運動学；化学 EJU 前 10 道的非计算题；数学 ベクトル、二次関数、三角関数（不用新增）。
- 计划：2026-11-19 起每周 5 天 × 每天 2 小时，到 2027-06-20 的 EJU。

## 要写的内容

1. **薄弱专题原创题**：上面 11 个薄弱点，每个约 20 题，按难度梯度：约 6 题 难度 1（概念入门、一步到位）、8 题 难度 2（EJU 标准）、6 题 难度 3（EJU 难题到校内考水平，不设上限）。数学用 EJU 答题卡 `blanks` 格式（引导式填空，和真题一样），理科用 `choice`。先查现有题库里这些考点已有多少题、哪些题型没覆盖，补空白，不要和已有题重复。
2. **校内考记述题**（新格式 `written`，形状见下）：先联网查清早稻田理工三学部 / 明治 / 青山学院 / 立教 / 中央 / 法政 的理工系**外国人留学生入试有没有自己的笔试、考哪些科目、什么形式**（另一位代理也在查，结论会写在 `design/school-exams.md`；你可以先自己查，写题时以有笔试的学校为准）。为有笔试的学校各写 1–2 套“风格一致的原创题”（不要照抄真题），每套 3–4 道大题，覆盖上面的薄弱考点为主。没有笔试的学校，就按它的出题水平写“院校水平拔高题”并在 label 里写清楚。
3. **无机背诵卡**：無機化学要背的东西（焰色反应、沉淀颜色与溶解性、气体制备与检验、离子分离流程、工业制法、金属/非金属单质与化合物的性质、颜色）做成一套间隔复习用的背诵卡。先看现有的“考点速测 / recall”题是什么格式（`shared/types.ts` 和 `content/bank/*`），能用就沿用（短选择题），约 120 张。有机流程题也配一组“反应路线速记卡”约 40 张。
4. **笔记**：给 11 个薄弱点各写或重写一篇考点笔记（`content/notes/`，沿用现有笔记格式）：知识框架、必背清单/公式、EJU 常见题型、易错点、30 秒自检。
5. **构建与校验**：`tools/v2/build-content.mjs` 不再把日语题、词汇打进 `content/dist/bank.json`（文件保留在仓库里，只是不进构建）；`tools/v2/validate.mjs` 支持 `written` 格式的校验（parts 非空、rubric 分数之和 = points、id 唯一等）。所有你写的文件都要过 `node tools/v2/validate.mjs <文件>`，最后 `node tools/v2/build-content.mjs` 通过。

```jsonc
  "written": {

      {
        "id": "1", "label": "(1)", "prompt": "（小问题干，可空）", "points": 10,

        "rubric": [ { "text": "列出 V = BLv", "points": 4 }, { "text": "…", "points": 6 } ],

      }
    ]
  },
  "explanation": { "zh": "…", "keyPoints": ["…"], "traps": ["…"] }
}
```

## 质量

- 每道题写完后**另起一遍独立重解**（不看自己写的答案），两次结果一致才算数；数值题用 python/sympy 算一遍核对；选择题的干扰项要对应真实的典型错误（解析里写出每个错误选项是怎么错出来的）。
- 需要图的题用简洁的 SVG 画（看现有题目的 figures 字段和 `public/assets` 下的做法），图要准确、标注清楚。
- 物理、化学的数值和常数按 EJU 惯例；化学用 2026 年新考纲的 ΔH 写法。
- 题目只供这台 Mac 上的个人学习，不上传不发布。
