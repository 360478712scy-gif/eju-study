# 澄学 EJU 3.0 — 交互与视觉规范

> 设计：Claude（美术与前端视觉）。引擎与题库：GPT（`design/api-contract.md`）。界面文字：Carbon（`app/src/copy/zh.ts`）。
> 旧版 `web/` 只作接口参考，3.0 的布局、组件、视觉全部重做，新前端在 `app/`。

## 0. 这个 App 给谁、怎么用

一个日语很好、目标早稻田 / MARCH 理工的学生。从 2026-11-19 到 2027-06-20 的 EJU，每周学 5 天、每天 2 小时，主攻弱项（物理：电磁感应、电容器、弹簧、单摆；化学：无机背诵、有机流程、热化学计算；数学：数列、排列组合、指数对数、积分/置换积分）。

**一句话体验**：打开就知道今天要干什么，点一下就进入一段被安排好的 2 小时；做完知道自己离目标更近了多少。其他一切（题库、错题、模考、数据）都在需要时才出现。

原则：
1. **一屏一件事**。每个页面只有一个主焦点和一个主操作。
2. **App 替他做决定**：顺序、配比、复习时机、难度都由引擎决定并说明理由；他只需要“开始”。想自己挑题时，练习页随时可用。
3. **安静的高级感**：空间感的毛玻璃浮层、发丝边框、柔光；不用花哨的颜色和装饰。做题时界面退后，题目最清楚。

## 1. 信息架构（7 个区 + 设置）

| 区 | 路由 | 内容 | 合并了旧版的 |
|---|---|---|---|
| 今天 | `#/` | 今日 2 小时的安排与“开始”；进行中的学习；AI 一句话点评 | 今日、跟学模式 |
| 计划 | `#/plan` | 到 6/20 的路线图（阶段、里程碑）、周视图、选学习日 | 冲刺计划 |
| 练习 | `#/practice` | 按考点 / 按真题卷 / 校内考 / 搜索 | 题库练习 |
| 复习 | `#/review` | 一个队列：到期错题 + 易错点 + 无机/有机背诵卡 | 错题本、易错点、考点速测 |
| 模考 | `#/mock` | EJU 整卷、校内考套卷、成绩回看 | 模考 |
| 笔记 | `#/notes` | 考点笔记 | 考点笔记 |
| 数据 | `#/insights` | 掌握度地图、预测分、时长、每周复盘 | 数据 |
| 设置 | `#/settings` | 目标、学习日、外观（场景/粒子/主题）、AI、数据导出 | 设置 |

做题器（`#/session/:id`）是全屏的专注模式，从任何地方进入都一样。

删掉：日语全部内容、词汇页、跟学模式的独立页面（并入今天）、易错点独立页（并入复习）。

## 2. 空间布局

整窗是一个“场景”：背景插画（按时间段自动换：清晨 / 白天 / 黄昏 / 夜晚，可在设置里固定），上面是几块悬浮的毛玻璃面板，底部一条悬浮胶囊。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ● ● ●                                     (透明标题栏，红绿灯浮在玻璃上)        │
│  ┌──────────┐ ┌───────────────────────────────────────┐ ┌───────────────┐    │
│  │ 导航面板  │ │                主面板                  │ │  侧面板(可选)  │    │
│  │ 澄学      │ │  页面标题区                            │ │  上下文：      │    │
│  │ 距考 214天│ │  页面内容                              │ │  今日队列 /    │    │
│  │ 今天      │ │                                       │ │  考点详情 /    │    │
│  │ 计划      │ │                                       │ │  AI 助教       │    │
│  │ ─ 题库 ─  │ │                                       │ │               │    │
│  │ 练习 复习  │ │                                       │ │               │    │
│  │ 模考      │ │                                       │ │               │    │
│  │ ─ 资料 ─  │ │                                       │ │               │    │
│  │ 笔记 数据  │ │                                       │ │               │    │
│  └──────────┘ └───────────────────────────────────────┘ └───────────────┘    │
│              ╭─────────────────────────────────────────────╮                 │
│              │ ◀  ▮▮  ▶ │ 当前任务 · 计时 │ 助教 笔记 音乐 │ ← 悬浮胶囊        │
│              ╰─────────────────────────────────────────────╯                 │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **导航面板** 216px，宽 ≤1080 时收成 64px 图标栏。顶部：品牌 + 倒计时；分组标题“学习 / 题库 / 资料”（小号、低对比），条目 = 图标 + 名称 + 右侧计数（如复习到期 12）。底部：头像位（目标院校）、设置。
- **主面板**：圆角 24，内边距 28/32，内容最大宽 1040。页面标题区：大标题 + 一行说明 + 右侧操作。
- **侧面板**（≥1360 宽时出现，否则收进主面板或抽屉）：轻微向内倾斜（`rotateY(-6deg)`，透视 1600px），像参考视频里的播放列表；做题时不出现。
- **悬浮胶囊**（Dock）：始终在底部居中，宽 auto，高 52。学习进行中显示：上一个 / 暂停继续 / 下一个、当前任务名与进度条、计时；空闲时显示：“开始今天”的快捷入口。右侧三个图标：AI 助教、笔记速查、背景音乐。按住助教图标可语音（以后做，先留位）。
- **视差**：鼠标移动时面板整体随鼠标轻微转动（最大 1.5°，带阻尼），背景反向位移 6px。做题器里关闭。尊重“减少动态效果”。
- **最小窗口** 960×680。设计以 1280×820 为主。

## 3. 材质（毛玻璃）

| 层 | 用途 | 夜（暗玻璃） | 昼（亮玻璃） |
|---|---|---|---|
| `glass-1` 面板 | 导航 / 主面板 / 侧面板 | `rgba(16,20,30,.46)` + blur 36 + saturate 160% | `rgba(244,247,252,.42)` + blur 36 + saturate 170% |
| `glass-2` 卡片 | 面板内的块 | `rgba(255,255,255,.055)` | `rgba(255,255,255,.38)` |
| `glass-3` 浮层 | 弹窗、菜单、胶囊 | `rgba(22,26,38,.62)` + blur 44 | `rgba(250,251,254,.62)` + blur 44 |
| `glass-read` 阅读 | 题干、解析、笔记正文 | `rgba(12,15,22,.70)` | `rgba(255,255,255,.78)` |

- 边框：1px 发丝 `rgba(255,255,255,.12)`（夜）/ `rgba(255,255,255,.55)`（昼），顶部内高光 `inset 0 1px 0 rgba(255,255,255,.08~.6)`。
- 阴影：大而柔 `0 30px 80px -20px rgba(0,0,0,.45)`，不用硬投影。
- 文字永远在足够不透明的层上：正文所在层的有效对比度 ≥ 4.5:1（题干、解析一律用 `glass-read`）。
- 圆角：面板 24 · 卡片 18 · 控件 12 · 胶囊/小标签 999。
- 颜色：主色是“冰蓝” `#8EC5FF`（夜）/ `#2F6FEB`（昼），只用于主操作、选中、进度。科目色只做识别：数学 冰蓝、物理 薰衣草紫、化学 薄荷绿。对 = 绿、错 = 珊瑚红（只在作答那一刻）、待复习 = 琥珀。
- 字体：系统字体（SF Pro / PingFang SC / Hiragino Sans），数字用等宽数字。字号阶梯 12 / 13 / 14 / 15 / 17 / 20 / 26 / 34 / 48。

## 4. 视觉焦点：光球

参考视频中央的磨砂光球，在这里是“今天的进度球”：
- 直径 180–220，磨砂玻璃球体（径向渐变 + 高光 + 内阴影），外圈一圈放射状刻度（120 格 = 120 分钟），已完成的刻度亮起。
- 球心：距考天数（大号数字）或进行中任务的剩余时间。
- 动：高光随鼠标缓慢移动；完成一个任务时刻度依次点亮一次。不做无限循环的呼吸光。

## 5. 各页面构图

**今天**：主面板左半是光球，右半是“今天的三件事”（像电台的台本：每行一条，当前那条亮，其余淡出）；下面一行是 AI 助教的一句话点评。主操作“开始今天的 2 小时”（胶囊上也有）。侧面板 = 今日队列（像歌单：序号、任务名、科目、分钟、状态），当前项有圆形播放键。非学习日：显示“今天休息”+ 可选的轻量复习 + 挪日按钮。

**计划**：上半是到 6/20 的路线图：一条横向时间轴，分阶段色带、里程碑旗标（12 月底 / 2 月底 / 4 月底 / 考前），“今天”是一个亮点。下半是周视图：7 天的竖条卡，学习日 = 亮玻璃、休息日 = 暗淡；点一天展开当天任务。右上：学习日选择（星期几的胶囊开关）。

**练习**：左侧是科目切换（三个大号分段：数学 / 物理 / 化学）+ 视图切换（考点 / 真题卷 / 校内考）。考点视图是“掌握度地图”：每个考点一块小玻璃砖，砖的亮度 = 掌握度，弱项有琥珀小点；点一块砖右侧面板出现该考点的详情（掌握度、已做、笔记入口、开始练习）。搜索在页面标题区右侧。

**复习**：一个队列。顶部三个数字（到期错题 / 易错点 / 背诵卡）和一个主按钮“开始复习”。下面按到期时间列出；背诵卡是翻卡体验（正面问题，空格翻面，按 1/2/3 自评）。

**模考**：两排大卡：EJU 整卷（数学 80 分钟 / 理科 80 分钟）与校内考套卷（早稻田 / 明治 / 中央……），每张卡显示上次成绩与下一次计划日期。成绩回看：分数环 + 各考点得失。

**笔记**：左列目录（按科目→单元），右侧阅读区（`glass-read`，舒适行宽 680）。弱项笔记置顶。

**数据**：顶部是预测分（区间条，目标是刻度线）与本周复盘卡；下方是掌握度热力（考点 × 周）、每日时长柱、速度散点。少即是多：每张图只回答一个问题。

**做题器（专注模式）**：导航面板和侧面板淡出，主面板居中加宽（最大 980），题干在 `glass-read` 上；选项是可点的玻璃行（悬停微亮，选中描主色边，提交后对/错着色）；数学答题卡是一排格子。胶囊变成题目控制：上一题 / 计时 / 下一题、标记“没把握”、问助教、答题卡总览。提交后解析从下方展开（思路 → 步骤 → 结论、考点、易错点）。记述题（校内考）：题干 + “写好了，看标准解答” → 标准解答 + 评分细则逐条勾选得分（也可以输入答案让 AI 批改）。

**AI 助教**：从胶囊右侧弹出的玻璃对话面板（参考视频的电台对话面板），宽 380，可贴靠右侧。上下文自动带当前题目 / 当前页面。消息气泡是小玻璃块；正在思考时显示一圈细刻度的转动。

**引导（首次打开）**：三步全屏玻璃卡：目标（院校、各科目标）→ 学习日（选 5 天、每天时长）→ 起点（上次成绩，已预填）。

## 7. 动效

- 时长 160 / 240 / 360ms，缓动 `cubic-bezier(.2,.8,.2,1)`；面板入场 = 透明度 + 上移 8px + 模糊 8→0。
- 页面切换：主面板内容交叉淡入（不动面板本身）。
- 粒子（雪 / 星尘）：canvas，默认低密度；做题器内自动暂停；设置里可关。
- 对的瞬间：选项边框变绿 + 勾号缩放 0.9→1；错不抖动，只变色并展开解析。
- 尊重 `prefers-reduced-motion`：关掉视差、粒子、入场模糊。

## 8. 快捷键

⌘1–7 切换七个区；Space 开始/暂停今天的学习；做题器里 1–9 选项、Enter 提交/下一题、←/→ 翻题、F 没把握、E 展开解析、/ 问助教；⌘K 搜索题目与笔记。

## 9. 文案槽位（交给 Carbon）

所有界面文字集中在 `app/src/copy/zh.ts`，按区分组（`nav`、`today`、`plan`、`practice`、`review`、`mock`、`notes`、`insights`、`session`、`coach`、`onboarding`、`settings`、`common`、`empty`、`toast`、`time`）。组件只引用键，不写死文字。动态文字用函数（例如 `today.leftDays(n)`）。语气：像一位靠谱的学长，简短、具体、有温度，不说教、不报告腔；中文为主，考点名可保留日语。
