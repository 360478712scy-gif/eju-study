# 澄学 EJU 2.0

为 **2026 年 11 月 8 日 EJU（2026年度第2回）** 重建的本机冲刺学习助手。目标 630（日本語 325 / 数学コース2 155 / 物理 72 / 化学 78），起点 539。双击桌面 **澄学 EJU.app** 打开；学习记录只保存在这台 Mac 上。

## 每天怎么用

1. 打开就是「今日」：按考试日顺序（日语 → 理科 → 数学）排好的任务块，点「开始」即做题。
2. 每题提交后立刻判分：选择题对答案，数学按 EJU 答题卡逐格判分；随后给出完整中文解析（思路 → 步骤 → 结论）、考点、易错点、考场速解和日语术语。
3. 做错、放弃或标记「猜的/没把握」的题自动进错题本：2 天后再练、再隔 4 天，间隔答对 2 次（选「确定」）才移出；数学错题重做时，上次做对的空会锁定，只重做错的部分。
4. 词汇分两种能力训练：**看字写读音**（答前不放音频）和**看词选意思**，各自间隔复习。
5. 「数据」页看预测分、每日时长、考点掌握热力图和做题速度。

## 19 天冲刺结构

| 阶段 | 日期 | 内容 |
|---|---|---|
| 专项突破 | 10/20–10/27 | 按「薄弱度 × 考频」轮换专题；每天理科限时小测练速度；日语读解、听解、文型、考点速测、词汇；错题混入专项回炉 |
| 套题实战 | 10/28–11/03 | 10/28、10/31、11/02 数理整卷模考（80 分钟×2），10/29 日语整卷模考，模考后第二天专攻暴露的弱点 |
| 考前调整 | 11/04–11/07 | 11/04 按考试日时间表全真模拟（建议 9:30 开始）；之后错题、考点速记、考前一页纸，11/07 自动减量 |

每天默认 6 小时，可在「今日」或「冲刺计划」里按天调整（含休息日）。计划每天根据真实作答生成：离目标最远的科目、掌握度低的考点分到更多时间；新题按天配给，保证到考前一直有没做过的题；错过的模考会排到下一个没有模考的日子。模考用到的真题卷在模考前不会出现在日常练习里。考前 10 天起「今日」会提示每晚收工时间，帮你把作息往 9:30 开考调。

## 题库（共 1120 题，全部经过第二个代理独立核验）

| 科目 | 官方真题 | 原创 | 合计 |
|---|---|---|---|
| 数学コース2 | 60 个大问（2015-2 至 2021-1，10 回） | 78（微积分、三角、数列/向量/复数、2026 新增确率分布、考点速测） | 138 |
| 物理 | 190 | 74（波动、电磁、交流/霍尔效应/半导体、考点速测） | 264 |
| 化学 | 200 | 82（无机、有机、焓变 ΔH 与溶度积等 2026 新写法、考点速测） | 282 |
| 日本語 | 138（2016-1 至 2018-1 公开的读解 46、听读解 18、听解 74，含原声音频） | 298（长短篇读解、合成语音听解、文型 120、理科术语速测） | 436 |

- 官方题按原卷逐字转写（KaTeX 公式、300 dpi 原图裁切），答案以官方正解表为准（两次独立录入核对），再独立重解核验，并写出中文详解（思路 → 步骤 → 结论、考点、易错点、考场速解、日语术语）。
- 日语模考：JASSO 公开卷不完整，模考时自动补原创题到考试题量（读解 25 题 / 40 分钟，听解约 27 题），这些补位题在模考前不会出现在日常练习里。
- **词汇** 810 个（含原 330 个词的重写释义与新例句、物理/化学/数学术语、读解与听解高频词），读音与词义分开训练；例句均有合成语音。
- **考点笔记** 70 篇：核心公式、EJU 常见题型、易错点、30 秒自检。

## 技术结构

```
server/        本机服务（Node 24 直接运行 TypeScript）：状态原子保存 + 滚动备份、静态文件、AI 讲解桥接
shared/        领域逻辑（类型、计划器、判分、间隔复习、统计、状态迁移），前后端与测试共用
web/           前端（React + Vite），构建产物在 web/dist
content/       题库源文件（bank/、vocab/、notes/、taxonomy.json），构建到 content/dist/bank.json
tools/v2/      渲染/裁图/校验/构建/语音合成工具
desktop/       原生 macOS 外壳（WKWebView）
tests-v2/      单元测试与端到端测试
legacy/v1/     1.4 版旧代码（只读存档）
```

- 学习记录：`data/state-v2.json`（首次启动时从 1.4 版 `data/state.json` 导入，旧文件不改动），备份在 `data/backups-v2/`（每 5 分钟最多一份，保留 80 份）。「设置 → 数据」可导出 JSON。
- 常用命令：`npm run build`（题库 + 前端）、`npm test`、`npm run typecheck`、`npm run validate`、`python3 launch.py --server-only`、`python3 launch.py --browser`。
- 启动器会检查服务版本，旧版本服务会被自动替换。端口 18763，只监听 127.0.0.1。
