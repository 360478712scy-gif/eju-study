# 澄学 EJU 2.0

为 **2026 年 11 月 8 日 EJU（2026年度第2回）** 重建的本机冲刺学习助手。目标 630（日本語 325 / 数学コース2 155 / 物理 72 / 化学 78），起点 539。双击桌面 **澄学 EJU.app** 打开；学习记录只保存在这台 Mac 上。

## 每天怎么用

1. 打开就是「今日」：按考试日顺序（日语 → 理科 → 数学）排好的任务块，点「开始」即做题。
2. 每题提交后立刻判分：选择题对答案，数学按 EJU 答题卡逐格判分；随后给出完整中文解析（思路 → 步骤 → 结论）、考点、易错点、考场速解和日语术语。
3. 做错、放弃或标记「猜的/没把握」的题自动进错题本：隔天重做，间隔答对 3 次（1/2/4 天）才移出。
4. 词汇分两种能力训练：**看字写读音**（答前不放音频）和**看词选意思**，各自间隔复习。
5. 「数据」页看预测分、每日时长、考点掌握热力图和做题速度。

## 19 天冲刺结构

| 阶段 | 日期 | 内容 |
|---|---|---|
| 专项突破 | 10/20–10/27 | 按「薄弱度 × 考频」轮换专题；每天日语读解、听解、词汇；错题回炉 |
| 套题实战 | 10/28–11/03 | 10/28、10/30、11/02 数理整卷模考（80 分钟×2），10/29 日语模考，其余日子限时小测 |
| 考前调整 | 11/04–11/07 | 11/04 按考试日时间表全真模拟；之后错题 + 考点速记，11/07 自动减量 |

每天默认 6 小时，可在「今日」或「冲刺计划」里按天调整（含休息日）。计划每天根据真实作答重新生成：错得多的考点、离目标最远的科目会分到更多时间；没完成的模考会顺延一天。模考用到的真题卷在模考前不会出现在日常练习里。

## 题库

- **官方真题（JASSO 公开过去问，仅供本机个人学习）**：2015-2 至 2021-1 共 10 回的数学コース2（60 个大问）、物理（190 题）、化学（200 题）；2016-1 至 2018-1 共 5 回公开的日语读解 46 题、听读解 18 题、听解 74 题（含原声音频与逐句原文）。
- 每题都按原卷逐字转写（KaTeX 公式、原图裁切），答案以官方正解表为准（两次独立录入核对），再由另一个代理独立重解核验，并写出中文详解。
- **原创补充**：2026 新考纲内容（确率分布・期待値・共分散、エンタルピー ΔH 写法、溶解度积、交流电路/霍尔效应/半导体等）、文型与接续表达、EJU 风格读解与合成语音听解（标注「原创」）。
- **考点笔记**：每个考点的核心公式、EJU 常见题型、易错点和 30 秒自检。

## 技术结构

```
server/        本机服务（Node 24 直接运行 TypeScript）：状态原子保存 + 滚动备份、静态文件、AI 讲解桥接
shared/        领域逻辑（类型、计划器、判分、间隔复习、统计、状态迁移），前后端与测试共用
web/           前端（React + Vite），构建产物在 web/dist
content/       题库源文件（bank/、vocab/、notes/、taxonomy.json），构建到 content/dist/bank.json
tools/v2/      渲染/裁图/校验/构建/语音合成工具
desktop/       原生 macOS 外壳（WKWebView）
tests-v2/      单元测试与端到端测试
legacy/v1/     1.4 版旧代码（只读存档）
```

- 学习记录：`data/state-v2.json`（首次启动时从 1.4 版 `data/state.json` 导入，旧文件不改动），备份在 `data/backups-v2/`（每 5 分钟最多一份，保留 80 份）。「设置 → 数据」可导出 JSON。
- 常用命令：`npm run build`（题库 + 前端）、`npm test`、`npm run typecheck`、`npm run validate`、`python3 launch.py --server-only`、`python3 launch.py --browser`。
- 启动器会检查服务版本，旧版本服务会被自动替换。端口 18763，只监听 127.0.0.1。
