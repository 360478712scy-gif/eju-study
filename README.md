# 澄学 EJU

为 2026 年 11 月 8 日 EJU 制作的本机学习空间。目标 630，当前基线 539，每天最多 240 分钟。侧重知识唤醒、EJU 引导式填空、速度与迁移验证。

## 打开与每天的使用

双击桌面 **澄学 EJU.app** 打开独立 Mac 窗口；没有地址栏、浏览器标签页或网页刷新按钮。`python3 launch.py` 也会打开这个窗口；维护时可用 `python3 launch.py --server-only` 只启动本地服务。学习记录仍保存在原项目，不随关窗删除。仅供这台 Mac 使用，未开放外网或 iPad 同步。

1. 从“知识预热”或今日任务开始：先闭卷回忆知识与日文术语，忘记的看分步例题，再遮住讲解完成应用检验。每张完成后自动进入“我的笔记本”，答错也如实保存。
2. 进入每日题单，完成指定题目、订正与闭卷产出；实际分钟默认为空，不以计划时长代填。
3. 卡住先写自己的尝试，再逐级看提示；可点击 Codex 获取针对本题的提示。
4. 答题后选择瓶颈，遮住解析写闭卷复述。看过 AI 或讲解应勾选借助提示。
5. 做错或看过提示的考点，次日优先安排未做过的同考点新题。词汇保留间隔回忆。题库不足时明确标记待补题，不把重复原题当作迁移。
6. 记录任务实际分钟。晚间保存复盘；本地规则先调整明天，Codex 教练可进一步提出建议，点击应用后生效。也可复制日报到原聊天讨论。

## 已内置

- 36 张知识卡、108 条术语记录（107 个不同日语词）：三角函数、积分、波、电磁、除杂、有机名称。每卡包含回忆提示、适用条件、分步例题、易错点和不同条件的应用题。记得的可直接验证，忘记的补学；1/3/7/14天回忆间隔，同日重做不延长。
- 笔记本保存卡片原文快照、原始回忆、术语回忆、应用结果、个人补充和重复学习历史。支持日文/中文搜索、科目与日期筛选、JSON导出；题目订正与词汇回忆也可回看。学习卡通过只代表该卡的回忆情况，不等于真题掌握。
- 33 天日历：常规日240分钟（含5分钟复盘），按疲劳和真实成果调整，最后3天明确减量。增加“计划评审”，逐块核算题量与产出，提前完成可做备用题。
- 理科以你80分钟完成25–30题为基线，首日24道官方题，95分钟包含约9.5分钟知识预热、65.5分钟首轮和20分钟订正。每次最多加2题，24→28→32→36的日期只是最早机会：最近3次独立首答、各科正确率、实测配速、完成率、疲劳与错题积压达标才增加。40题/80分钟挑战还需额外门槛，次日安排40分钟复盘；未解决项继续保留。
- 官方数学60题组、物理190小题、化学200小题、日语91听力题与46阅读小问；另有330词项、115道原创非词汇短练。词项、大题组与小题不混算；后半程包含明确的间隔复习。题页、官方答案、听力原文和音频按题号连接。数学长题按小题组保留引导关系，需要对照官方答案自评。
- 不是完整历年真题全集。旧题用于训练，不等于覆盖 2026 年全部考纲。官方题附专题提示；并非每道官方题均已编写完整详解。
- 独立首答、提示后作答、超时、错因和闭卷复述分别记录。没有把自测正确率换成 EJU 尺度分。
- 1、3、7、14 天间隔回忆；新题验证通过后更新原薄弱点的迁移记录。
- 6 项成就、星点、4 种休息奖励、2 种可解锁配色。休息无需先赚星点，也不惩罚断签。
- 专注计时、3 首本地轻钢琴、官方真人听力。首次开窗自动播放 BGM，手动暂停的偏好会记住；播放词音、例句或听力时 BGM 静音，结束后恢复。关闭窗口停止声音。
- 全部330词项和日语例句、107个知识术语提供离线日语合成发音，支持0.8/1/1.2倍速。新版词汇答题前不提供读音；提交后显示读音、解释与播放按钮，笔记中也可播放。
- 灰原哀 MP4 动态壁纸，可选静态/关闭；进入题目或页面后台时暂停，并遵守系统减少动态效果设置。

## Codex 教练

使用本机已登录的 Codex CLI；软件内默认 **gpt-6.1-sol / high**，已接入分级题目提示、日报计划建议和词汇板块汇报。提示与计划建议在点击时请求；新版词汇板块完成后自动请求汇报，使用当前账户额度。它接收题目/原题图片与当前尝试，或学习摘要，不自动读取原聊天上下文。

桥接使用 `codex exec --ephemeral --sandbox read-only --output-schema`，通过 stdin 传入资料，不拼接 shell 命令。忽略无关用户插件配置，禁用 shell 工具和网页搜索；保留现有登录，显式指定 `--model gpt-6.1-sol -c model_reasoning_effort="high"`，不改用户全局 Codex 配置。计划经过日期、科目、时长及真实调度器的题单覆盖检查，展示实际题量/产出后由用户点击应用，模型不直接改写学习记录。单次只运行一个请求，可取消，150 秒超时。

AI 解释不等于官方答案；数学和化学问题应核对过程。离线练习不依赖 Codex。连接错误不清空记录。

官方参数依据：https://learn.chatgpt.com/docs/models 、https://learn.chatgpt.com/docs/config-file/config-reference

## 数据与维护

- `data/state.json`：学习状态。每次修改原子保存，保留最近 30 份快照于 `data/backups`。
- `data/ai-history`：软件内教练请求结果，可回看计划建议。
- 应用窗口本地保存未提交题目会话、页面草稿、音乐音量和壁纸偏好。已提交记录在本机服务中，关窗和升级桌面入口不会删除。
- “资料与备份”可以导出 JSON；备份恢复请关闭服务后核验再替换，避免覆盖新记录。
- Node 24；无运行时 npm 依赖。`node server.mjs`；测试 `npm test`、`npm run test:ui`。真实 CLI 联测 `node tests/live-coach-v2.mjs` 或 `node tests/live-coach-sol.mjs` 会使用账户额度，普通测试不调用模型。
- 不要重新运行 `tools/integrate_*.py` 等一次性开发迁移脚本。

## 2026-10-06 工作量评审修正

旧版首日标注240分钟，但题目宽松限时仅合计69分钟，完成记录也默认填计划时长。v1.2删除了这一默认值，按题型首答配速、实际音长、明确订正对象和回忆产出安排任务。至少5个同类型不同题的首次独立正确样本才校准配速；同日重答不延长复习间隔。新增官方题依旧使用官方答案表自评，并未自动批改。未经细考点核验的题对不充作迁移证明；仅两组新增官方题对已逐图核验，其他缺口会显示待补题。

`tests/workload-audit.json` 是33天逐日保留历史的供给模拟，不是用户实际学习记录。正常日的4小时是工作预算；预计不等于实际，做完可以提前结束或取备用题。`tests/browser-v2-results.json` 与 `tests/learning-browser-results.json` 是隔离状态的浏览器验收（含笔记重启保留与移动端流程）；`tests/live-coach-v2-result.json` 是隔离模拟日报的真实CLI预览结果。

## 1.3 桌面操作

- `⌘1` 今日学习、`⌘2` 课前复习、`⌘3` 我的笔记、`⌘4` 复盘。
- `⌘⇧M` 播放/暂停音乐；`⌘⇧F` 开始/暂停专注；`⌘/` 查看快捷键。
- `Esc` 逐层关闭右键菜单、快捷键帮助、图片放大或练习弹窗；日语输入法候选优先。
- 标准复制、剪切、粘贴、撤销、全选及系统关窗/退出保留。右键菜单针对编辑框提供对应操作。
- 独立窗口阻止网页刷新、后退和拖入文件/URL跳转。原题图在应用内放大，官方外部来源在系统浏览器打开。
- 正在作答时，导航快捷键不会替换当前练习；草稿本地保留。切换音乐不会重建正在编辑的页面。
- `desktop/` 保存原生壳源码、构建脚本和旧桌面入口备份；本机服务与学习数据仍在项目目录。

软件测试使用隔离学习记录。1.3 的桌面与保存面板历史验收保存在 `tests/native-desktop-results.json`；1.4 的词汇流程使用下列专用验收。浏览器集成与实际 WKWebView 桌面验证分开保存证据；真实模型联测只在显式运行测试脚本时使用额度。

## 1.4 第一天成果与词汇改进

第一天旧版 40 题中 39 题正确，用时共 316 秒；用户补充全程听音作答，没有看题干。旧答题、提示标记及已完成计划保留原样，这个成绩不用于判断看字回忆读音的能力。用户的输入方式说明另存为观察记录。

- 未开始的新计划安排 24 次看字写假名、12 次释义选择、4 次换语境、8 次订正后遮住答案复测，共 48 次作答，约 15 分钟。阅读与听力预算保留，日常总预算仍为 240 分钟。已开始的今天保持原任务；首页提供“补练 10 词”。
- 三种能力分开判分与安排复习。答错、想不起来、提示后答对及同日复测分别保存；同日重做不延长掌握间隔。词汇读音按假名规范客观判分，选择题按题库标准答案判分，不由模型自由改分。
- 330 个词有词义、读音与音频；第一天涉及的 40 词增加人工核对的释义和语境选择题，未审核的模式不出题。
- 答题页铺满窗口，底部固定操作区。所有科目共用 Enter 下一题；日语选择题可开启“选后自动下一题”，其他科目不自动跳题。假名输入框 Enter 提交，中文/日语输入法选词和多行汇报保留原操作。
- 每次提交自动记答案和前台用时、写入词汇笔记；隐藏窗口、切走页面不继续计时。普通产出块也自动计时，纸上补充时间独立填写。
- 每块完成自动排队生成 AI 汇报；用户自述单独保存，点击下一板块时自动保存未提交自述。相同作答不重复请求 AI；失败明确显示，可重试。报告后台完成不会覆盖期间的新答案。
- `npm test` 检查判分、计划、报告与计时；`npm run test:japanese` 检查真实浏览器交互；`npm run test:japanese:native` 检查真实 AppKit/WebKit 交互。`node tests/live-vocab-report.mjs` 单独调用真实 Codex，会使用账户额度，样本和数据均隔离。

### 词音修正（2026-10-06）

用户指出「圧力」的音频将拗音读开。对照合成证实：本机 Kyoko 的「あつりょく」与错误「あつりよく」声学结果近乎相同；「張力」也有同类问题，「ちゅうしゅつ」与错误「ちゅうしゆつ」更产生相同 PCM。三词改用对应汉字作为明确合成输入，保留原标准 reading 与判分规则；「抽出」的知识卡术语共用修正后的词音。其余词不作未经核验的全库转换。

生成器记录实际 `speechText`，覆盖策略和输入一起参与音频 ID，避免复用旧文件。旧音频和发布前 manifest 留存，可回溯；发布后重新打开桌面窗口以清除旧索引。证据在 `tests/pronunciation-fix-20261006/`。声学对照用于发现合成输入被混同，文件/解码测试用于验证播放；两者不等于母语者逐词听审，全词库尚未完成逐词听审。

随后按用户要求完成全库定向审查：430 个共用词音、529 组逐位置对照、全部 760 条音频解码与哈希验证，另检查 35 条高风险例句。新增修正提出、反射、補助金、対処、接触、必修、ローレンツ力，以及「バスで10分ほど」例句；攪拌和依存接受合法异读，分別读音题加上垃圾分类语境。完整结果、来源和未确认项见 `tests/pronunciation-audit-20261006/REVIEW.md`。这次完成的是声学对照、文字与播放审查，未完成人耳逐条听审。
